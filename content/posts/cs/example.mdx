## Co je Blue Team?

**Blue Team** je defenzivní tým v organizaci zodpovědný za ochranu infrastruktury, detekci hrozeb a reakci na incidenty. Zatímco Red Team hledá slabiny, Blue Team je opravuje a buduje obranu.

## Klíčové oblasti

### 1. Monitoring a detekce

Základem je nepřetržitý monitoring pomocí **SIEM** (Security Information and Event Management):

```yaml
# Příklad Sigma pravidla pro detekci brute-force útoku
title: Multiple Failed Login Attempts
status: experimental
logsource:
  category: authentication
  product: windows
detection:
  selection:
    EventID: 4625
  condition: selection | count() by TargetUserName > 10
  timeframe: 5m
level: medium
tags:
  - attack.credential_access
  - attack.t1110
```

### 2. Incident Response

Strukturovaný proces reakce na bezpečnostní události:

1. **Příprava** – procesy, nástroje, tým
2. **Identifikace** – detekce a klasifikace incidentu
3. **Omezení** – izolace postiženého systému
4. **Eradikace** – odstranění hrozby
5. **Obnova** – návrat do normálu
6. **Poučení** – post-incident review

### 3. Threat Hunting

Proaktivní hledání hrozeb, které prošly skrz automatickou detekci:

```bash
# Hledání podezřelých PowerShell spuštění
Get-WinEvent -FilterHashTable @{
    LogName='Microsoft-Windows-PowerShell/Operational'
    Id=4104
} | Where-Object {
    $_.Message -match 'EncodedCommand|Invoke-Expression|IEX|bypass'
} | Select-Object TimeCreated, Message -First 20
```

| Kategorie | Nástroj | Popis |
|-----------|---------|-------|
| SIEM | Splunk, Elastic SIEM | Agregace a analýza logů |
| EDR | CrowdStrike, Defender for Endpoint | Detekce na endpointech |
| IDS/IPS | Suricata, Snort | Síťová detekce |
| Forensics | Volatility, Autopsy | Forenzní analýza |
| Threat Intel | MISP, OpenCTI | Sdílení IoC |

## MITRE ATT&CK Framework

Každý Blue Team specialista by měl znát **MITRE ATT&CK** – knowledge base taktik a technik útočníků. Pomáhá:

- Mapovat detekční pokrytí
- Identifikovat mezery v obraně
- Komunikovat s Red Teamem společným jazykem

> ATT&CK je jako mapa nepřátelského území. Čím lépe ji znáš, tím lépe se bráníš.

## Jak začít v Blue Teamu?

1. **Nauč se základy sítí** – TCP/IP, DNS, HTTP
2. **Pochop operační systémy** – Windows Event Logs, Linux syslog
3. **Vyzkoušej si SIEM** – Elastic Stack si můžeš rozjet doma
4. **Studuj MITRE ATT&CK** – začni s nejčastějšími technikami
5. **Řeš laby** – Blue Team Labs Online, CyberDefenders

## Závěr

Blue Team není jen o reagování na incidenty. Je to o budování **proaktivní bezpečnostní kultury** v organizaci. A hlavně – je to nekonečný proces učení, protože útočníci se nikdy nezastaví.
